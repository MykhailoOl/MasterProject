## Additional technical checks

Provider adapters reject output-limit termination even when the content is valid JSON. Grok Responses rejects incomplete/failed statuses. Per-attempt configuration and failures remain in the call trace, including provider/model fallback attempts outside strict study mode. Missing returned model identity is logged as unknown.

The source ledger distinguishes structural merge from successful processing. `hasCheckedSource` requires both the processed ID and a verified source check. Snapshots require every saved source to satisfy that condition. Confirmation preserves check verdicts and freezes the summary, while the exporter refuses missing frozen summaries and legacy collections.

Study projects require a pinned configured provider/model and strict model selection. Continuing them checks the frozen model and support setting. The application blocks incomplete setup rather than silently collecting an unmatched study session. The default dataset preserves randomized failures and missing outcomes for intention-to-treat accounting. Manual/external assignments can be inspected through diagnostics but are not silently represented as randomized.

Existing concurrency protections remain: answer-before-model commit, short project locks, expected-revision checks, duplicate-answer idempotency, read-only GETs, stale-export invalidation, ownership and CSRF enforcement. No application database or real provider credentials were used in verification.

## Boundaries and tradeoffs

A second call to the same LLM can share the extractor's mistakes. These changes close the automatic-success and unsupported-excerpt pathways and provide a semantic-check gate; they do not prove entailment or measure hallucination rates. Passing mocked verifier tests demonstrates control flow, not the model's judgment. The second call also adds latency and cost to both study arms.

The study compares the implemented taxonomy-guided selection policy with the specified general interview under common stopping and support rules. Guided prioritization and probe choices are part of that policy; these tests do not identify an isolated causal effect of taxonomy labels independent of the selection algorithm. Participant early finish can still produce different lengths. Prespecify timing, early stopping, repeated participation, missing outcomes and secondary analyses, and measure them.

Review is shared between arms, so evaluate both pre-review and confirmed revisions. Internal taxonomy coverage is not a correctness/usability outcome. Use blinded independent assessment and an observed pilot with beginners. Stable model snapshots and real provider contract/quality checks remain prerequisites for collecting a defensible dataset.
